# Motion graphics

**Owned by Language App: to be written there.** Prello will read it and not write its own.

Seed notes from Prello (Language App may revise or drop):
- Stack that worked: HTML + CSS + GSAP for motion, three.js/WebGL for texture, rendered frame by frame in headless Chrome (HyperFrames), encoded with ffmpeg. See `../video/coded-films-workflow.md`.
- Every frame is a pure function of time; seeded noise only.
- Pause at any second: something meaningful is mid-flight; no idle wobble or float.
- 0.3-0.75 s stillness before a result lands. Only 2-3 transition types, never a crossfade.
- Elias asked (2026-10-09) that a "/motion" skill be used for all motion graphics; which skill exactly is still unconfirmed.
