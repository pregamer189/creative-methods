# Emotion graphics

Our working meaning: **motion, sound and small characters that carry a feeling**,
so the product tells you how you're doing without words. It sits on top of
`../motion-graphics/ui-motion.md` (how things move) and answers a different
question: what should the user *feel* at this moment, and what makes them feel it?

Grounded in Elias's ideas I21 (tiny living details), I27 (sound through
everything, special moments, easter eggs) and I28 (complexity woven into simple
means), 2026-10-26, and in the "no guilt" rule every product here follows.

## Rules

1. **Name the feeling first.** For each moment write one line: what happened, what
   the user should feel (proud, curious, calm, surprised), and the one cue that
   carries it (a motion, a sound, a character's reaction).
2. **One moment per screen.** Everything else stays quiet so the moment lands.
3. **Always upbeat.** Every outcome ends on a good sound and a kind motion, even a
   light or failed day. Low effort gets a smaller celebration, never a sad one.
4. **No guilt, no fear.** No crying mascots, no "you'll lose it", no red alarms, no
   countdowns meant to scare. Setbacks are shown honestly and calmly, with the way
   back visible.
5. **Change you can see.** Small animations that show progress or skill ("you're
   getting better") beat numbers. The product changes a little as the user grows.
6. **Tiny living details.** Small characters or objects that react to what the
   user does (a bird hops when you finish, a page settles when you save). They
   react to actions, they don't idle-loop for attention.
7. **Rare things stay rare.** Special animations for real milestones (an even
   streak, a first, a new level) and a few easter eggs. If it happens every day it
   is not special: scale it down.
8. **Sound through everything, quietly.** Whoosh, tick, chime, a world sound that
   fits the scene. Short, optimistic, never tiring; fully usable muted.
9. **Simple surface, rich underneath.** The delight comes from craft in small
   parts, not from adding screens or effects (I28).
10. **Respect the user's settings.** Reduced motion keeps the feeling through sound
    and a still change; sound off keeps it through motion.

## Moment sheet (copy per moment)

| Field | Example |
|---|---|
| Trigger | Finished today's session |
| Feeling | Proud, a little playful |
| Visual cue | The progress object moves up one step with a small spring |
| Sound | Rising three-note chime, under 600 ms |
| Haptic | Success notification |
| Scale by outcome | Great: full move + chime. Light day: half move + softer chime |
| Never | A sad sound, a loss animation, a guilt line |
| Reduced motion | Object swaps state, chime still plays |

## Checks

- Every moment has a filled sheet before it's built.
- Watch it at the worst outcome: is it still kind?
- Watch it ten days in a row (fast-forward): does it get old? If so, add variation
  or make it rarer.
- One outside eye: does a person who didn't build it say the feeling you named?
