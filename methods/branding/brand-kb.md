# Brand knowledge base (template)

Elias, I15, I63, I70 (2026-10-26 to 10-31): marketing is branding; every weak
video damages the brand; build a personal brand and project brands that Claude
can create with. One file per brand, kept in that brand's own repo or project
(never here). Every film, post and reply is made from it.

## Sections

| Section | What goes in it |
|---|---|
| Who | The people behind it, where they are, what they really do. Dated facts |
| Projects | Each project, its status, and the one brand rule that keeps it apart from the others (own audience, own voice) |
| One line | Who we are, in one sentence a stranger understands |
| Pillars | 3-4 themes; every post fits at least one |
| Voice | How it sounds: sentence length, words used, words never used (hype, fake urgency, guilt) |
| Look | Pointer to the design tokens (colours, type, motion); never copied values |
| Say now / say later | Claims that are true on a real screen today, and claims that wait until they are |
| Video look | Light, setting, colours per film, music feel, voice, how many subtitles |
| Don'ts | The never-again list (from `../video/editing-rules.md` plus the brand's own) |
| Proof we can show | Real things that exist today, with paths |

## Rules

- Mark anything not confirmed by the owner as "draft".
- A product's name stays out until it is chosen; no placeholder names.
- Each project keeps its own audience and voice; never mix them unless asked.
- Update the file the moment the owner decides something.
