# Storyboards

One page per film, written before anything is built or shot, so the maker never
improvises and every note can point at one shot. Works for shot films, coded
films and screen recordings. Paste-ready version: `skills/video-storyboard/SKILL.md`.

## How to write one

1. Start from `storytelling.md`: five lines, one sentence, one trust step, a turn.
   Bring 2-3 items from the taste board (`../research/taste.md`).
2. Pick the music first and measure it (first downbeat, bar length). Shot times
   sit on its bars.
3. Fill the template below. Every shot is one image and one move
   (`editing-rules.md`); a new shot only on a new action.
4. For coded films, add the seam plan: for each cut, the axis, direction and the
   element that carries the eye.
5. Score the idea (`../research/idea-rail.md`) and record the owner's opinion
   next to it, not inside it.
6. Run the plan checks of `film-quality-gate.md` section 1 before building.

## Template

```markdown
# NNN · Title

**One idea (one sentence):**
**Trust step:** curiosity / understanding / belief / action
**Shape:** (from storytelling.md)
**Length and format:** e.g. 35 s, 9:16 master + 16:9
**Look:** the product's tokens (name the two main colours); flat colours with designed texture, no gradients
**Five lines:** situation / desire / conflict / change / result
**Taste:** 2-3 items from the taste board, and what to take from each
**Music:** tempo, mood, track; first downbeat at __ s, bar = __ s; dips at __
**Voice:** which voice; takes per sentence
**Sound family:** the one pack or palette
**Finish:** 2-3 keywords; colours (dominant, secondary, accent); texture; frame rate
**Score:** outside __ · owner: like / unsure / dislike

## Shots

| # | Time (bars) | Shot (wide / close / action / screen) | Move | What happens | Text or voice | Sound | Seam out (axis, direction, carrier) |
|---|---|---|---|---|---|---|---|
| 1 | 0:00-0:02 (1-2) | | | | | | |

## Assets

Per shot: what exists, what must be made, what may not be generated without a yes.

## Extras (shot films)

Cutaways worth filming in case the edit needs them.

## Check before showing

- [ ] Hook works muted in 2 s
- [ ] One idea only; nothing extra
- [ ] Every claim true on a real screen today
- [ ] No same-scene cuts; 2-3 transition types
- [ ] The product's own rules hold (name, palette, banned music)
- [ ] An outside eye watched it
```

## Common mistakes

- Shots listed without times on the music grid: the edit drifts off the beat.
- Two ideas in one film because both were good: make two films.
- A shot that is "the same screen, zoomed": that's a same-scene cut.
- No sound column: every event that matters needs a sound or a chosen silence.
