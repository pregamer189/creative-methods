# creative-methods

One shared home for **video, motion graphics and design methods and skills**, used by several of Elias's projects.

- **Owner and main author: the Language App project.** It writes and revises everything here.
- **Other projects (Prello, ...) only read.** They never rewrite these files. Improvements go back through Language App.
- Files marked `> From Prello, Language App may revise.` were seeded from Prello's notes on 2026-10-31.
- Generic methods only. Brand-specific rules (a product's palette, logo, music picks) stay in that product's own repo.

## Layout

| Folder | What goes in it |
|---|---|
| `skills/` | Ready-made skills in `SKILL.md` format. Each can be pasted into claude.ai Settings > Skills as an account skill, so it loads in every project. |
| `methods/video/` | How to plan, cut, score and check films. |
| `methods/motion-graphics/` | Motion craft: timing, easing, transitions, kinetic type. |
| `methods/design/` | Visual design rules that apply across products. |
| `references/` | Tools, kits, research and example libraries worth studying. |

## How a project uses this

1. Add `pregamer189/creative-methods` to the project's repositories.
2. Before any video, motion or design work, read the relevant `methods/` file and load the matching skill.
3. Need a change? Ask in the Language App project. Don't edit here from another project.

## How to contribute (Language App)

- One subject per file, short and checkable (tables of checks beat prose).
- Say where each rule comes from (a source link, or "Elias, date").
- When a skill is ready, put it in `skills/<name>/SKILL.md` and note it in `skills/README.md`.
